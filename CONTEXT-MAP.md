# Карта контекстов Daevox

Карта связывает предметные контексты платформы с workspace, которые ими владеют.

## Контексты

- [Взаимодействие с Daevox](apps/web-client/CONTEXT.md): пользовательский интерфейс для чатов и
  постановки agentic-задач.
- [Выполнение agentic-задач](apps/backend/CONTEXT.md): серверная часть платформы, принимающая и
  координирующая agentic-задачи.
- [Транспортный фреймворк Daevox](lib/framework/CONTEXT.md): общая транспортная основа для HTTP,
  WebSocket, внутренних событий и фоновых задач.

## Связи

- **Взаимодействие с Daevox → Выполнение agentic-задач**: веб-клиент передаёт сформулированные
  пользователем agentic-задачи backend и отображает ход их выполнения.
- **Выполнение agentic-задач → Транспортный фреймворк Daevox**: backend использует framework для
  транспортных интерфейсов и инфраструктурных механизмов выполнения.
- **Agentic-задача ≠ задача framework (`Job`)**: agentic-задача выражает пользовательскую цель,
  тогда как `Job` является инфраструктурной единицей независимого выполнения внутри framework.
