# Реализовать регистрацию HTTP-контроллеров и маршрутизацию

Реализовать согласованный контракт из [`../spec.md`](../spec.md) в `lib/framework/`.

## Требования

- Создать `Application`, `HttpControllerBase`, внутренний `HttpRouter` и согласованные классы ошибок.
- Реализовать атомарную регистрацию HTTP-контроллера и нормализацию его статических метаданных.
- Реализовать сопоставление статических и динамических HTTP-маршрутов с детерминированным приоритетом.
- Добавить unit-тесты на успешную регистрацию и сопоставление, нормализацию, параметры, приоритет, конфликты, атомарность, наследование, неизменяемость и каждый класс ошибок.
- Использовать только JavaScript в файлах `.js` и встроенные возможности Node.js; runtime-зависимости не добавлять.
- Сохранить существующую исполняемую точку входа для sandbox-тестирования и не добавлять библиотечную точку входа.
- Добиться успешного выполнения `npm run check`.

## Критерии приёмки

- Поведение соответствует всем разделам `spec.md`.
- Все исходные файлы реализации находятся в `lib/framework/`.
- `HttpRouter` не реэкспортируется как пользовательский публичный API.
- Регистрация контроллера либо добавляет всю пачку HTTP-маршрутов, либо не изменяет состояние.
- Результат сопоставления не зависит от порядка регистрации.
- HTTP runtime и выполнение HTTP-обработчиков не реализуются в рамках задачи.
