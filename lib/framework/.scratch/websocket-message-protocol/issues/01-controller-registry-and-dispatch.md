# Реализовать каталог WebSocket-контроллеров и диспетчеризацию событий

Реализовать декларативный контракт `static name` и `static events` из [`../spec.md`](../spec.md), заменив `static path` и controller-level `onMessage`.

## Требования

- Добавить строгую атомарную регистрацию контроллеров и событий с копированием метаданных.
- Проверять wire-имена, уникальность, точную форму `{ name, handler }` и собственные методы прототипа.
- Создавать новый экземпляр контроллера с `{ jobRunner }` для каждого сообщения.
- Удалить `clientSessions` из `WebSocketControllerBase`.
- Реализовать последовательную диспетчеризацию сообщений одной сессии по `controller/event`.
- Добавить и экспортировать согласованные ошибки регистрации.
- Покрыть контракт unit-тестами только в `.js`.

## Критерии приёмки

- Метаданные после регистрации не зависят от пользовательских объектов.
- Конфликты не оставляют частично зарегистрированного состояния.
- Handler получает `{ body, clientId, sessionId, signal }` без raw socket.
- Поведение соответствует разделам «WebSocket-контроллер» и «Диспетчеризация и ответ» спецификации.
- `npm run check` завершается успешно.
