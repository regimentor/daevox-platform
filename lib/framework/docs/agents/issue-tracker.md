# Трекер задач: локальные Markdown-файлы

Задачи и спецификации этого репозитория хранятся в виде Markdown-файлов в `.scratch/`.

## Соглашения

- Для каждой функциональности создаётся отдельный каталог: `.scratch/<идентификатор-функциональности>/`.
- Спецификация хранится в `.scratch/<идентификатор-функциональности>/spec.md`.
- Каждая задача реализации хранится в отдельном файле `.scratch/<идентификатор-функциональности>/issues/<NN>-<идентификатор>.md`. Нумерация начинается с `01`; объединять все задачи в один файл нельзя.
- Состояние триажа указывается строкой `Status:` в начале файла задачи. Допустимые значения описаны в `triage-labels.md`.
- Комментарии и история обсуждения добавляются в конец файла под служебным заголовком `## Comments`. Текст комментариев ведётся на русском языке.

## Жизненный цикл задачи

- Только задача со статусом `ready-for-agent` входит во фронтир автономного агента.
- После выполнения добавить краткий итог в `## Comments` и установить `Status: resolved`.
- Задача со статусом `resolved` является исторической записью и не содержит исполняемых инструкций.
- Перед повторным открытием задачи сверить её требования с ближайшим `AGENTS.md`, обновить устаревшие пути, команды и соглашения, затем установить подходящий активный статус.

## Когда навык требует опубликовать задачу в трекере

Создать новый файл в `.scratch/<идентификатор-функциональности>/`, при необходимости создав каталог.

## Когда навык требует получить связанную задачу

Прочитать файл по указанному пути. Обычно пользователь передаёт путь или номер задачи напрямую.

## Операции навигации

Используются навыком `/wayfinder`. **Карта** содержит по одному дочернему файлу на каждую задачу.

- **Карта:** `.scratch/<инициатива>/map.md` со служебными разделами `## Destination`, `## Notes`, `## Decisions so far`, `## Not yet specified` и `## Out of scope`. Содержимое разделов ведётся на русском языке.
- **Дочерняя задача:** `.scratch/<инициатива>/issues/NN-<идентификатор>.md`, начиная с `01`, с вопросом под служебным заголовком `## Question`. Строка `Type:` содержит тип задачи (`research`, `prototype`, `grilling` или `task`), а строка `Status:` — состояние `claimed` или `resolved`.
- **Блокировка:** строка `Blocked by: NN, NN` в начале файла. Задача разблокирована, когда все перечисленные задачи имеют состояние `resolved`.
- **Фронтир:** найти в `.scratch/<инициатива>/issues/` открытые, незаблокированные и ещё не взятые задачи; первой выбирается задача с наименьшим номером.
- **Взятие в работу:** установить `Status: claimed` и сохранить файл до начала работы.
- **Завершение:** добавить ответ под служебным заголовком `## Answer`, установить `Status: resolved`, затем добавить в раздел `## Decisions so far` файла `map.md` краткое резюме и ссылку на контекст.
