# Платформа и зависимости

Фреймворк предназначен для Node.js 26, использует ESM с `"type": "module"` и запускается без Babel и других преобразователей. HTTP-слой строится на `node:http` и других встроенных `node:*` API; по умолчанию проект не имеет runtime-зависимостей, а сторонняя зависимость допускается только после доказательства необходимости и явного согласования.
