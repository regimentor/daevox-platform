# Транспортно-специализированные контроллеры

`Application` остаётся общей точкой композиции для HTTP и будущих транспортов WebSocket и gRPC, поэтому транспортные компоненты получают явные имена: `HttpControllerBase`, `HttpRouter` и `registerHttpController`. Каждый регистрируемый HTTP-контроллер обязан напрямую наследовать пустой пока `HttpControllerBase`: это отказывается от структурной совместимости в пользу явной принадлежности контроллера к транспорту и единой точки будущего расширения его контракта. `HttpRouter` остаётся внутренним компонентом приложения и не входит в пользовательский публичный API.
