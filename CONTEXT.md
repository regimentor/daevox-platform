# Транспортный фреймворк Daevox

Контекст фиксирует единый язык HTTP-фреймворка и различия между его основными понятиями.

## Язык

**Приложение (`Application`)**:
Общая точка композиции транспортных возможностей, предоставляемых фреймворком.
_Избегать_: HTTP-приложение, сервер, контейнер.

**HTTP-контроллер (`HttpController`)**:
Группа связанных HTTP-возможностей, опубликованных под общим префиксом.
_Избегать_: контроллер, сервис, endpoint.

**HTTP-маршрут (`HttpRoute`)**:
Соответствие HTTP-метода и пути обработчику контроллера.
_Избегать_: маршрут, endpoint, URL.

**HTTP-обработчик (`HttpHandler`)**:
Операция HTTP-контроллера, на которую указывает HTTP-маршрут.
_Избегать_: обработчик, action, callback.

**HTTP-маршрутизатор (`HttpRouter`)**:
Каталог HTTP-маршрутов приложения, используемый для сопоставления HTTP-запроса с HTTP-маршрутом.
_Избегать_: маршрутизатор, dispatcher.

**Контекст HTTP-запроса (`HttpRequestContext`)**:
Нормализованное представление данных одного HTTP-запроса и сигнала его отмены, доступное HTTP-обработчику без транспортных объектов Node.js.
_Избегать_: контекст запроса, request, payload.

**HTTP-ответ (`HttpResponse`)**:
Явно заданный HTTP-обработчиком статус, заголовки и тело результата обработки HTTP-запроса.
_Избегать_: ответ, result, response object.

**WebSocket-контроллер (`WebSocketController`)**:
Именованная группа связанных WebSocket-событий протокола.
_Избегать_: контроллер, socket handler, channel, endpoint.

**WebSocket-событие (`WebSocketEvent`)**:
Именованный вид сообщения протокола, принадлежащий одному WebSocket-контроллеру.
_Избегать_: сообщение, route, action.

**Сообщение WebSocket-протокола (`WebSocketProtocolMessage`)**:
Сообщение между клиентом и приложением, адресованное парой WebSocket-контроллера и WebSocket-события и содержащее JSON-совместимый объект тела.
_Избегать_: WebSocket frame, payload, request, response.

**WebSocket-сессия (`WebSocketSession`)**:
Одно WebSocket-соединение клиента, имеющее уникальный `sessionId` и существующее до закрытия соединения.
_Избегать_: клиент, вкладка, socket.

**WebSocket-клиент (`WebSocketClient`)**:
Созданная фреймворком техническая сторона одной WebSocket-сессии, имеющая уникальный `clientId` на время этой сессии.
_Избегать_: пользователь, аккаунт, несколько соединений.

**Хранилище WebSocket-сессий (`WebSocketSessionStore`)**:
Внутренний каталог WebSocket-сессий и связанных с ними WebSocket-клиентов.
_Избегать_: controller state, client registry.

**Исполнитель задач (`Job Runner`)**:
Внутренний компонент приложения, принимающий классы задач и передающий их на выполнение в пул работников.
_Избегать_: handler runner, controller worker.

**Задача (`Job`)**:
Работа, описанная пользователем как класс с контрактом выполнения и выполняемая независимо от обработки HTTP-маршрута.
_Избегать_: request, handler.

**Пул работников (`Worker Pool`)**:
Среда изолированного выполнения задач, управляющая работниками и распределением работы между ними.
_Избегать_: worker manager, job runner.
