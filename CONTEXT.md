# HTTP-фреймворк Daevox

Контекст фиксирует единый язык HTTP-фреймворка и различия между его основными понятиями.

## Язык

**Приложение (`Application`)**:
HTTP-приложение, составленное из зарегистрированных контроллеров.
_Избегать_: сервер, контейнер.

**Контроллер (`Controller`)**:
Группа связанных HTTP-возможностей, опубликованных под общим префиксом.
_Избегать_: сервис, endpoint.

**Маршрут (`Route`)**:
Соответствие HTTP-метода и пути обработчику контроллера.
_Избегать_: endpoint, URL.

**Обработчик (`Handler`)**:
Операция контроллера, на которую указывает маршрут.
_Избегать_: action, callback.

**Маршрутизатор (`Router`)**:
Каталог маршрутов приложения, используемый для сопоставления HTTP-запроса с маршрутом.
_Избегать_: dispatcher.

**Контекст запроса (`RequestContext`)**:
Данные одного HTTP-запроса в форме, доступной обработчику.
_Избегать_: request, payload.

**Исполнитель задач (`Job Runner`)**:
Среда выполнения задач, отделённых от обработки HTTP-запросов.
_Избегать_: handler runner, controller worker.

**Задача (`Job`)**:
Работа, выполняемая независимо от обработки маршрута.
_Избегать_: request, handler.
