# AGENTS.md — Node.js framework

## Правила работы агентов

- Выполнять изменения кода, архитектуры и документации только по явному запросу пользователя.
- Исходный код и тесты писать только на JavaScript в файлах `.js`; TypeScript и файлы `.ts`/`.tsx` в проекте запрещены.
- Для нового и изменяемого production-кода в `lib/framework/*.js` писать двуязычный JSDoc: английский текст перед русским; документировать классы, методы, функции, константы, внутренние структуры и значимые поля, указывать `@public` или `@private`, затем выполнять `npm run docs:build`.
- При конфликте задачи с принятыми архитектурными решениями сначала описать конфликт и запросить решение пользователя.
- Для архитектурных задач перед работой прочитать связанные ADR из `docs/adr/`.
- Для терминов предметной области использовать определения из `CONTEXT.md`.
- Для пользовательского назначения и публичного API сверяться с `README.md`.

## Agent skills

### Issue tracker

Задачи и спецификации хранятся локально в Markdown-файлах внутри `.scratch/`. См. `docs/agents/issue-tracker.md`.

### Triage labels

Локальные задачи используют стандартный словарь меток триажа. См. `docs/agents/triage-labels.md`.

### Domain docs

Репозиторий использует одноконтекстную структуру документации. См. `docs/agents/domain.md`.
