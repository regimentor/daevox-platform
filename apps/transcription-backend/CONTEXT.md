# Транскрибация, перевод и озвучка медиа

Контекст описывает получение текста из записи и подготовку перевода для просмотра с озвучкой.
Глоссарий охватывает существующую транскрибацию и согласованный сценарий перевода; он не обозначает
готовность реализации перевода.

## Язык

**Транскрипт**:
Текст распознанной речи с привязкой к моментам исходной записи и доступными метками спикеров.
_Избегать_: перевод, озвучка.

**Спикер**:
Выделенный говорящий внутри одной записи. Метка спикера не устанавливает личность человека
и не гарантирует его узнавание в другой записи.
_Избегать_: синтетический голос, пользователь.

**Назначение голоса**:
Выбор синтетического голоса для озвучивания реплик спикера внутри записи. Один голос может
использоваться для нескольких спикеров без объединения их меток.
_Избегать_: идентификация спикера, клонирование голоса.

**Закадровый перевод**:
Озвученный перевод, звучащий поверх приглушённого оригинала с сохранением временной связи
с исходной записью.
_Избегать_: полная замена исходной речи, клонирование голоса.

**Фраза озвучки**:
Короткая смысловая часть речи с привязкой к словам и времени исходной записи, для которой
подготавливается перевод и синтетическая речь. Несколько фраз могут принадлежать одному блоку спикера.
_Избегать_: блок спикера, весь монолог.

**Группа одновременной речи**:
Перекрывающиеся реплики, переводы которых размещаются последовательно в общем временном интервале
и свободной паузе до следующей группы.
_Избегать_: один спикер, смешанный синтетический голос.

**Неполный перевод**:
Доступный для просмотра результат с явно отмеченными фрагментами, для которых перевод или
пригодная озвучка не подготовлены. В этих фрагментах воспроизводится оригинал.
_Избегать_: полностью готовая озвучка, полный отказ обработки.
