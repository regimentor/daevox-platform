# Выполнение agentic-задач

Контекст фиксирует язык серверной координации agentic-задач Daevox независимо от транспорта и
конкретных механизмов выполнения.

## Язык

**Agentic-задача (`AgenticTask`)**:
Сформулированная пользователем цель, для достижения которой платформа координирует работу агентов и
доступные им возможности.
_Избегать_: задача framework, `Job`, запрос, prompt.

**Агент (`Agent`)**:
Участник выполнения agentic-задачи, который рассуждает, использует доступные возможности и производит
результат в рамках поставленной цели.
_Избегать_: worker, bot, модель.

**Agentic harness (`AgenticHarness`)**:
Среда выполнения и оркестрации agentic-задач, управляющая работой агентов и доступом к необходимым
возможностям.
_Избегать_: framework, worker pool, job runner.

**Запланированная задача (`ScheduledTask`)**:
Agentic-задача, запуск которой инициируется заданным расписанием.
_Избегать_: cron job, задача framework, таймер.

**Память пользователя (`UserMemory`)**:
Персистентные сведения о пользователе, доступные агентам между его чатами.
_Избегать_: история чата, состояние сессии, cache.

**Telegram-сессия (`TelegramSession`)**:
Авторизация Daevox для доступа к одному личному Telegram-аккаунту, сохраняемая между запусками
платформы. Завершение Telegram-сессии означает выход из этого аккаунта в Daevox.
_Избегать_: JWT Daevox, пользователь, сетевое соединение.

**Пользователь backend**:
Человек, использующий локальный экземпляр Daevox и управляющий его подключением к личному
Telegram-аккаунту. Отдельная учётная запись Daevox для этой роли не предполагается.
_Избегать_: демо-пользователь БД, Telegram-аккаунт, агент.

**Telegram-чат (`TelegramChat`)**:
Переписка в Telegram, доступная подключённому личному аккаунту; отдельна от чата пользователя с Daevox.
_Избегать_: чат Daevox, `Chat`, Telegram-сессия.

**Наблюдение за Telegram-чатом**:
Явно включённый пользователем сбор сообщений выбранного Telegram-чата для последующей обработки
секретарём.
_Избегать_: подключение Telegram, прочтение сообщения.

**Архив Telegram-сообщений**:
Сохранённая переписка из наблюдаемых Telegram-чатов, служащая исходным материалом для последующей
обработки агентом.
_Избегать_: память пользователя, `UserMemory`, Telegram-сессия.

**Период наблюдения**:
Промежуток, за который новые сообщения выбранного Telegram-чата должны попадать в архив согласно
намерению пользователя. Временная недоступность Daevox сама по себе не завершает этот период.
_Избегать_: Telegram-сессия, время работы приложения.

**Пробел архива**:
Известная неполнота сохранённой переписки или сведений об её изменениях. Возобновление текущего сбора
само по себе не означает устранение пробела.
_Избегать_: ошибка подключения, очередь обработки, отсутствие новых сообщений.

**Явное возобновление наблюдения**:
Решение пользователя продолжить сбор выбранного Telegram-чата с текущего момента, когда после сбоя
невозможно установить непрерывность прежнего периода. Неопределённый промежуток остаётся вне сбора.
_Избегать_: повторный вход, повторное подключение, восстановление полного архива.

**Дневное саммари Telegram-чата**:
Сводка доступной переписки одного Telegram-чата за определённый день. Готовое дневное саммари этого
чата служит источником сведений для автоответчика.
_Избегать_: память пользователя, архив Telegram-сообщений, саммари всех чатов.

**Автоответчик Telegram-чата**:
Явно включаемый пользователем секретарь, отвечающий от имени подключённого аккаунта на новые чужие
сообщения выбранного Telegram-чата с обозначением авторства ИИ.
_Избегать_: наблюдение за Telegram-чатом, Telegram-бот, дневное саммари.
