# Трекер задач: локальные Markdown-файлы

Задачи и спецификации этого репозитория хранятся в виде Markdown-файлов в `.scratch/`.

## Область действия

- Этот файл описывает трекер для общих задач monorepo и workspace, у которых нет собственной конфигурации.
- Задачи, относящиеся только к фреймворку, хранятся в `lib/framework/.scratch/` и следуют правилам из `lib/framework/docs/agents/issue-tracker.md`.
- Общесистемные и межконтекстные задачи хранятся в корневом `.scratch/`.
- Одну задачу не следует дублировать одновременно в корневом и package-local трекерах.

## Соглашения

- Для каждой функциональности создаётся отдельный каталог: `.scratch/<feature-slug>/`.
- Спецификация хранится в `.scratch/<feature-slug>/spec.md`.
- Каждая задача реализации хранится в отдельном файле `.scratch/<feature-slug>/issues/<NN>-<slug>.md`. Нумерация начинается с `01`; объединять все задачи в один файл нельзя.
- Состояние триажа указывается строкой `Status:` в начале файла задачи. Значения описаны в `triage-labels.md`.
- Комментарии и история обсуждения добавляются в конец файла под заголовком `## Comments`.

## Когда навык требует опубликовать задачу в трекере

Создать новый файл внутри `.scratch/<feature-slug>/`, при необходимости создав каталог.

## Когда навык требует получить связанную задачу

Прочитать файл по указанному пути. Обычно пользователь передаёт путь или номер задачи напрямую.

## Операции навигации

Используются навыком `/wayfinder`. Карта содержит по одному дочернему файлу на каждую задачу.

- **Карта:** `.scratch/<effort>/map.md`, содержащий разделы Notes, Decisions-so-far и Fog.
- **Дочерняя задача:** `.scratch/<effort>/issues/NN-<slug>.md`, начиная с `01`. Строка `Type:` содержит тип задачи (`research`, `prototype`, `grilling` или `task`), а строка `Status:` — состояние `claimed` или `resolved`.
- **Блокировка:** строка `Blocked by: NN, NN` в начале файла. Задача разблокирована, когда все перечисленные задачи имеют состояние `resolved`.
- **Фронтир:** найти открытые, незаблокированные и ещё не взятые задачи; первой выбирается задача с наименьшим номером.
- **Взятие в работу:** установить `Status: claimed` и сохранить файл до начала работы.
- **Завершение:** добавить ответ под заголовком `## Answer`, установить `Status: resolved`, затем добавить ссылку на контекст в Decisions-so-far файла `map.md`.
