# Метки триажа

Навыки используют пять канонических ролей триажа. Эта таблица сопоставляет роли со значениями меток в локальном трекере проекта.

| Метка в mattpocock/skills | Метка в нашем трекере | Значение                                                 |
| ------------------------- | --------------------- | -------------------------------------------------------- |
| `needs-triage`            | `needs-triage`        | Сопровождающий должен оценить задачу                     |
| `needs-info`              | `needs-info`          | Ожидается дополнительная информация от автора            |
| `ready-for-agent`         | `ready-for-agent`     | Задача полностью описана и готова для автономного агента |
| `ready-for-human`         | `ready-for-human`     | Для выполнения требуется человек                         |
| `wontfix`                 | `wontfix`             | Задача не будет выполняться                              |

Когда навык упоминает каноническую роль, следует использовать соответствующее значение метки из этой таблицы.
