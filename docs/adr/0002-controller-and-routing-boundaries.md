# Границы контроллеров и маршрутизации

Контроллеры публикуют статические декларативные метаданные маршрутов, доступные без создания экземпляра. Маршрут ссылается на обработчик по имени метода и не содержит `execution`, `moduleUrl`, `exportName` или иных worker metadata; экземпляр контроллера создаётся только после нахождения маршрута. `Router` только регистрирует и сопоставляет маршруты: он не выполняет обработчик и не записывает HTTP-ответ.
