# Выполнение запросов и жизненный цикл

Обработчики контроллеров всегда выполняются в основном потоке приложения, а фоновые задачи передаются `Job Runner` в пул Worker. `IncomingMessage`, `ServerResponse` и socket не входят в `RequestContext`; результаты всех обработчиков проходят единый процесс нормализации ответа. Отмена и тайм-ауты должны иметь явную семантику и обязательную очистку ресурсов.
