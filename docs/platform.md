# Daevox Platform

Daevox Platform — платформа для agentic-задач: пользователь формулирует задачу, а платформа
предоставляет необходимые интерфейсы и среду для её выполнения агентами.

## Целевые возможности

### Чаты

Чаты должны поддерживать:

- персистентную память о пользователе, доступную между разговорами по аналогии с ChatGPT;
- веб-поиск;
- запуск субагентов;
- вызов инструментов (tool calls).

### Agentic harness

Платформа должна предоставлять agentic harness — среду выполнения и оркестрации agentic-задач.

### Запланированные задачи

Платформа должна позволять создавать задачи, которые запускаются по расписанию.

## Компоненты

### Frontend

Пользовательский интерфейс находится в [`apps/web-client`](../apps/web-client/).

### Backend

Backend будет находиться в `apps/backend`. Этот workspace пока не настроен.

Backend будет реализован на [`@daevox/framework`](../lib/framework/README.md) — фреймворке,
который разрабатывается в `lib/framework` специально как основа серверной части Daevox Platform.

## Текущее состояние

- frontend workspace существует;
- backend workspace ещё не настроен;
- framework находится в разработке;
- перечисленные возможности описывают целевой функционал платформы, а не статус их реализации.
