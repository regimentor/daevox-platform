# Проверка реализации, 2026-09-10

Автоматические проверки: 41 backend-тест прошёл, 4 опциональных GPU/model-теста
пропущены. Четыре браузерных сценария voiceover и четыре сценария transcription
прошли. Web unit-тесты: 13 passed. Python/web typecheck, Ruff, Oxlint для файлов
voiceover и production-сборка web-client прошли.

## Переключение GPU

По запросу пользователя ASR по умолчанию переключён с RTX 5080 на RTX 4070 Ti.
Диаризация и TTS уже использовали RTX 4070 Ti. HTTP-регрессия сначала падала
на прежней настройке, после изменения проходит. Внешний тестовый процесс
проверяет переданное устройство; реальные модели проверены отдельно.

При запуске проверки `nvidia-smi` показал 11700 MiB свободной памяти на RTX 4070 Ti.
Проверен сохранённый источник пользовательской записи
https://www.youtube.com/watch?v=XqmOZ1TyLCk (303,60 с), через настоящий HTTP API
TestClient с настоящими модельными процессами. ASR и диаризация выполнялись
параллельно на второй карте, завершились за 18,53 и 10,47 с. Получено 73 фразы.
Ранее этот источник завершался ошибкой распознавания; после переключения GPU
ошибка не повторилась. Это подтверждает работоспособность текущей конфигурации,
но не устанавливает точную причину прежнего обобщённого RuntimeError.

Текущий локальный сервер вернул модель `Ornith-1.5-9B`; модель не переключалась.
Первые 24 перевода получены. Контрольный запуск остановлен после проверки GPU,
без ожидания полного перевода и рендеринга. Снимок сохранён в игнорируемом
`apps/transcription-backend/data/second-gpu-result.json`.

Работающий API перезапущен с RTX 4070 Ti и идентификатором текущей LLM.
Изменённый default GPU действует и при последующих обычных запусках; модель LLM
нужно передавать через `TRANSCRIPTION_LLM_MODEL`, как описано в README.

## Границы проверки

Предыдущий отдельный прогон с контрольным транскриптом и реальными LLM/Silero
подготовил пять образцов и итоговую озвучку. Он не является проверкой полного ASR
pipeline. Браузерные тесты используют модельные doubles.

Приёмка из issues/07-acceptance.md целиком не завершена: три контрольных источника,
часовое видео, ручная оценка смысла, качества голосов и длительной синхронизации
ещё требуют проверки. Не считать автоматические тесты подтверждением этих пунктов.

## Исправление пропусков после пользовательской проверки

Причины: JSON в Markdown-обёртке отвергался парсером; предложения разрывались на границе восьми секунд; слова с нулевым таймингом становились отдельными фразами; строгий срок исключал слишком длинную озвучку. Исправлены парсер, группировка и подгонка по измеренной длительности. Пользователь явно изменил приоритет на сохранение речи с локальным отставанием и восстановлением тайминга в паузах. Предел ускорения 1,15× сохранён.

Полный контрольный прогон старого строгого режима: 71 фраза, 12 пропусков duration_overflow. После изменения политики источник заново обработан реальными моделями: 72 фразы (ASR между прогонами изменил сегментацию), все 72 включены в дорожку, completed, problems пуст. Фрагменты озвучки не перекрываются.

Максимальное отставание: 1.473 с; возвратов к исходному времени после отставания в паузах: 5. Видео: 304.226 с, аудио: 304.226 с. Последние слова заканчиваются на 304.226 с; хвост сохранён удержанием последнего кадра. Медиа доступны через HTTP.

Результат в библиотеке: http://127.0.0.1:5173/voiceover/12d44bf2-03e9-4990-87e9-f2cdf50df43a. Машинный отчёт: `apps/transcription-backend/data/full-coverage-verification.json` (игнорируемые локальные данные). Проверка подтверждает включение фраз, не является независимой оценкой точности перевода или произношения всех терминов.

Проверки после исправлений: 47 backend-тестов passed, 4 opt-in теста skipped; 4 браузерных сценария passed; Ruff и mypy passed. Тесты покрывают перенос длинной фразы без наложения, сохранение хвоста в обоих медиафайлах, целые предложения, нулевые тайминги, временной бюджет LLM, повторное сокращение и JSON-обёртку.

Актуальный runtime: LLM Ornith-1.5-9B после перезапуска заняла RTX 4070 Ti; ASR, диаризация и TTS работающего API перенесены на свободную RTX 5080 через переменные окружения. Внешний LLM-сервер не останавливался и модель не менялась.
