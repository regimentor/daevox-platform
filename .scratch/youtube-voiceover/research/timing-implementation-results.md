# Реализация и проверка тайминга Qwen

Дата: 2026-09-11. Исходник: «Is Rust taking over GPU programming?», 303.600907 с.
Контрольная точка до изменений: `6296a65`.

## Результат и границы вывода

На полном **контрольном варианте с дополнительной вычиткой переводов агентом**
максимальное отставание по границам окон составило **1.74225 с**. Все 62 окна
размещены в видео исходной длительности; речь заканчивается на 290.997375 с,
далее сохраняется финал исходника. Обработка WAV не превышает 1.15×.

Это не доказательство, что любой полностью автоматический запуск локального
Ornith даст такой результат. Для контрольного видео были дополнительно вычитаны
компактные переводы; исключены пять более коротких автоматических вариантов,
терявших оттенки исходного смысла. LLM-проверка сама иногда ошибается:
например, пропуск «день назад» может получить одобрение. Порог тайминга и
проверка чисел/терминов объективны в своих пределах; проверка смысла моделью
остаётся эвристикой.

| Вариант Serena 1.7B | Длительность результата | Максимальное отставание |
|---|---:|---:|
| Предыдущий результат | 340.686 с | 43.690 с |
| Вычитанный компактный текст, один нейтральный синтез, старый ASR | 317.297 с | 15.087 с |
| Исправленный ASR + выбор измеренного нейтрального/быстрого варианта | 303.601 с | **1.742 с** |

Отставание здесь — задержка начала окна / превышение границы следующего окна,
не пословный lip-sync. Новые и старые окна различаются вследствие исправления
ASR и объединения зависимых оборотов; нельзя интерпретировать разницу как
чистый эффект одной настройки TTS.

## Что изменено в приложении

- Qwen 1.7B подключён отдельным процессом в изолированном окружении. Голоса
  Serena, Aiden, Uncle Fu доступны через API и интерфейс. Silero сохранён как
  совместимый режим. Инструкции обоих вариантов Qwen требуют нейтральной подачи.
- Whisper для озвучки использует VAD и не переносит текст предыдущего окна.
  Обычная транскрибация сохраняет прежние настройки.
- Консервативное объединение зависимых оборотов сохраняет исходные слова,
  таймкоды и идентификаторы; границы разных спикеров и overlap не склеиваются.
- LLM получает бюджет времени и запрос на три компактных формулировки. Формат
  ограничен JSON Schema; отдельно проверяются числовые литералы и наличие
  терминов. Английское множественное число GPU/GPUs нормализуется. Устранение
  повтора термина допустимо. Словарь расширяется настройкой.
- Для Qwen выполняется отдельный семантический аудит и до двух повторных
  переводов отклонённого окна. Некорректный ответ не означает одобрение.
- Синтезируются допустимые тексты в двух нейтральных манерах. Выбор происходит
  по фактическому WAV после обработки длинных тихих пауз. Сохраняются края и
  запас 120 мс возле речи; полностью тихая запись не вырезается.
- При необходимости продолжается сокращение с учётом измеренной длительности.
  Паузы источника поглощают накопившееся отставание. При превышении настройки
  `VOICEOVER_MAX_LAG` (по умолчанию 2 с) результат явно отмечается `incomplete`
  с `timing_overflow`; успешно созданная речь остаётся доступна целиком.

## Отдельно найденная причина отставания

Старый ASR на 85 с вставлял повтор «We can see that Rust is not incidental to
this role», выделив ему 0.72 с. Он повторял реальную более раннюю фразу из 36 с.
Повторное распознавание участка 75–105 с и всего исходника убрало вставку.
В финальной паузе старый ASR также выдавал «Thanks for watching / I'll see you
next time» с почти нулевыми длительностями; полный проход с VAD заканчивает
распознанную речь на 292.18 с.

Регрессия воспроизведена **через HTTP с настоящим Whisper**: до изменения тест
падал на наличии `not incidental` в участке 80–90 с; после изменения прошёл.
Диаризация и прочие модели в этом специализированном тесте заменены внешними
модельными doubles. Это не полная проверка всего реального API-конвейера.

## Сравнение с F5-TTS Russian

Экспериментальная среда: `f5-tts==1.1.17`, torch/torchaudio 2.11.0,
`hotstone228/F5-TTS-Russian` revision
`4b9fcb51e68b0b7e96dbc8c9df3d80b4a835b914`, safetensors и собственный vocab.
Референс — уже синтезированная нейтральная фраза Serena длительностью 5.6 с.
Это не независимое сравнение голосовых идентичностей.

В этой версии `fix_duration` включает референс. Для каждой фразы передавалось
5.6 с + целевая длительность; одна фраза передавалась одним batch, без деления
целевого времени между несколькими кусками. В новой upstream-реализации
механика чанков может отличаться. [Исходный код F5](https://github.com/SWivid/F5-TTS/blob/main/src/f5_tts/infer/utils_infer.py).

| Фраза | Естественный F5 | Цель | F5 с целью |
|---|---:|---:|---:|
| Найм инженеров | 7.477 с | 6.840 с | 6.827 с |
| Перечень обязанностей | 10.752 с | 9.680 с | 9.664 с |
| QTile | 3.499 с | 2.700 с | 2.688 с |
| Причина выбора Rust | 7.936 с | 6.880 с | 6.859 с |

Численный контроль длительности работает. Однако диагностический Whisper
показывает искажения и пропуски английских названий, особенно в коротком QTile.
Дополнительные четыре пробы с фонетической записью Rust/GPU/AMD/QTile не решили
проблему целиком. В QTile распознаётся «Или это блочная система…», без названия.
Это сигнал для прослушивания, а не достоверная автоматическая оценка каждого
фонемного различия. F5 не подключён как основной движок.

У весов F5 Russian лицензия CC-BY-NC-SA-4.0: использованы для локального
исследовательского сравнения. Для коммерческой поставки понадобится подходящая
лицензия или другая модель. [Карточка модели](https://huggingface.co/hotstone228/F5-TTS-Russian).

## Проверка аудио и артефакты

Все 62 финальных окна Qwen проверены независимым распознаванием Whisper.
Пропусков целых окон нет; произношение имён остаётся отдельным вопросом:
например, Rust часто распознаётся как «рост», NVIDIA в одном фрагменте —
искажённо. ASR не заменяет пользовательское прослушивание. У одного нейтрального
синтеза короткое «Спасибо за просмотр» неожиданно заняло 14 с: это дополнительная
причина измерять несколько вариантов, а не доверять длине текста.

Локальные большие файлы находятся в игнорируемом
`apps/transcription-backend/data/timing-research/`:

- `best-video/preview.mp4` — контрольный ролик с русской речью и тихим оригиналом;
- `best-result.json`, `best-asr.json` — точные тайминги и диагностическое ASR;
- `compact-reviewed.json` — дополнительно вычитанные тексты;
- `audited-translations.jsonl` — результаты автоматического перевода/аудита;
- `source-clean-asr.json` — повторное распознавание полного источника;
- `f5-results.json`, `f5-pronunciation-results.json`, `f5-asr.json` — F5-пробы;
- `asr-http-before.log`, `asr-http-after.log` — красный/зелёный реальный HTTP-тест;
- `comparison.html` — страница сравнения.

Установка Qwen и параметры запуска описаны в README backend. Тестовые серверы
останавливаются после тестов; постоянный backend в ходе этой задачи не поднят.
