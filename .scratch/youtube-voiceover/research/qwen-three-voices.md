# Сравнение трёх голосов Qwen3-TTS 1.7B

2026-09-11. Подготовлены три полные пробные версии того же ролика: Aiden, Uncle_Fu, Serena. Приложение и база библиотеки не менялись, backend не запускался.

Модель `Qwen3-TTS-12Hz-1.7B-CustomVoice`, revision `0c0e3051f131929182e2c023b9537f8b1c68adfe`. Auto, BF16/SDPA, RTX 5080; три голоса генерировались пакетами для каждой фразы. Seed 1234 + индекс фразы, max_new_tokens=2048. Использована прежняя отдельная среда qwen-env.

Одинаковая инструкция для всех голосов:

> Read this technical narration in a neutral, matter-of-fact voice. Use even intonation, consistent volume, clear articulation and a steady normal speaking pace with short natural pauses. No dramatic emphasis, excitement, sadness, laughter, sighs, or added interjections. Read only the supplied text.

Одинаковые 72 сохранённых перевода, без новых LLM-подмен или сокращений. Нейтральность задана инструкцией, субъективная оценка её соблюдения остаётся за прослушиванием.

Генерация 216 WAV заняла 251.28 с после загрузки модели; peak allocated PyTorch 5323 MiB (не полная память устройства).

| Голос | Итог, с | Максимальное отставание, с |
| --- | ---: | ---: |
| Aiden | 345.86 | 49.91 |
| Uncle_Fu | 391.70 | 93.83 |
| Serena | 340.69 | 43.69 |

Исходник 303.60 с. В полноразмерных версиях ускорение речи ограничено 1.15×; все записи сохранены, хвост продолжается на последнем кадре. Видео 1080p H.264 + AAC, оригинал приглушён до 10%. Это сравнение голосов, не готовая синхронная интеграция.

Короткие preview.wav содержат одни и те же первые три фразы без ускорения, с паузой 0.25 с между фрагментами. Дополнительное выравнивание громкости не применялось.

Проверка: идентичность входных текстов для каждого голоса, 72 записи на вариант, PCM mono 24kHz, порядок размещения без перекрытий, максимум скорости, сохранение хвоста, длительности и кодеки MP4. Диагностическое распознавание выполнено на 24 фрагментах (по 8 на голос, включая начало/середину/конец); пустых транскриптов нет. Полнота каждого произнесённого слова этим не доказана.

В контрольных фразах ASR часто распознаёт Rust как «рост»/REST. Для Uncle_Fu один GPU получился KPU; для Serena распознано «увидела» при исходном «увидел». ASR может ошибаться; эти места требуют прослушивания. Смена модели сама по себе не заменяет глоссарий и контроль произношения.
