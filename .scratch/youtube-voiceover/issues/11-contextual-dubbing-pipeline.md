# Контекстный перевод видео и синхронизированная RU-дорожка

Status: resolved
Type: task

## Цель

Переделать существующий конвейер перевода видео: анализ аудио → распознавание →
сегментация с таймкодами → контекстный перевод → адаптация длительности → CosyVoice
с голосами спикеров → синхронизация → отдельная русская аудиодорожка с фоном.

Реализовать и проверить конвейер, а не ограничиваться проектированием. Схема задана
пользователем как желаемое поведение; она не является описанием внутренних алгоритмов YouTube.

## Решение пользователя и приоритет требований

Пользователь согласовал перенос плана в локальную задачу для запуска в отдельном чате.
Эта задача фиксирует новую итерацию после первоначальной [спецификации](../spec.md).
В пределах этой итерации она заменяет прежние ограничения на использование образцов
голосов спикеров, повторную обработку отдельных реплик, переиспользование промежуточных
результатов и скачивание RU-дорожки. Остальные совместимые контракты сохраняются.
Очередь задач, публичный сервис и облачные перевод/TTS в объём не входят.

### Обязательные ограничения

- Не возвращать проверяющую модель, проверки смысла, полноты, чисел или терминов.
  Единственное условие принятия перевода — непустой текст для соответствующей реплики.
  Разбор ответа и сопоставление ID необходимы для работы конвейера.
- Измерение длительности аудио используется для синхронизации, а не аудита перевода.
- Сохранять исходную временную шкалу и длительность видео. Не замораживать последний
  кадр и не обрезать слова ради совпадения длительности.
- Тембр и подачу задавать при синтезе через аудиообразцы и поддерживаемые возможности
  CosyVoice. Не обещать точного восстановления интонации оригинала.
- Хранить полный перевод отдельно от адаптированного текста озвучки.
- Сохранять промежуточные результаты для повторной обработки отдельных реплик.
- Сохранить работоспособность библиотеки, плеера, прогресса, отмены, ошибок и удаления.
- Сохранить чужие незакоммиченные изменения. Перед работой прочитать применимые AGENTS.md.
- Не останавливать работающую LLM ради освобождения GPU. Перед перезапуском backend
  проверять отсутствие активной обработки.

## План реализации

### 1. Сохраняемые результаты этапов

Определить структуры для исходника и его длительности, слов с таймкодами, спикеров
и образцов, реплик с устойчивыми ID и временными окнами, контекста ролика, полного
и адаптированного перевода, аудиофрагментов и итогового размещения.

Ключи кэша должны учитывать входные данные, модели и настройки. Изменение реплики
инвалидирует только зависимые результаты. Обеспечить совместимость старых записей,
в том числе с ранее назначенными голосами других TTS-движков.

### 2. Сегментация и временные окна

Собирать законченные реплики с учётом пунктуации, пауз и смены спикера; ограничить
чрезмерно длинные фрагменты. Сделать исходный язык параметром с сохранением рабочего
сценария английский → русский; не заявлять поддержку направлений без проверки.

Рассчитывать доступное время по исходной шкале, включая свободные паузы. Явно
обработать перекрывающуюся речь: не допускать неограниченного сдвига остатка ролика.

### 3. Общий контекст перевода

Один раз сформировать тему ролика, имена, термины и согласованные варианты перевода.
Передавать контекст вместе с исходными репликами и соседним текстом, переводить
смысловыми блоками с сохранением ID. Учитывать размер контекстного окна локальной LLM.
Контекст не заменяет исходный текст. Последующего аудита перевода нет.

### 4. Адаптация до TTS

Сначала получить полный перевод, затем адаптировать текст под временной бюджет.
Сохранение информации задаётся инструкцией адаптатору, без проверяющей модели.
Предварительная оценка длительности приблизительна и калибруется по фактическому TTS.
Убрать обязательный синтез нескольких вариантов каждой реплики.

### 5. Голоса спикеров

Выбирать чистые образцы без наложения чужой речи и по возможности без музыки.
Учитывать ограничения текущего CosyVoice: образец до 30 секунд, частота от 16 кГц.
Использовать устойчивый образец для всех реплик спикера. При отсутствии пригодного
образца использовать назначенный запасной голос и показывать это в интерфейсе.
Предусмотреть ручную замену образца или выбор готового голоса.

### 6. Синтез и ограниченная подгонка

Синтезировать один основной вариант, измерить длительность и сохранить, если он
помещается. При переполнении повторно адаптировать и синтезировать только проблемную
реплику. Ограничить число повторов; ориентир максимального ускорения — текущие 1,15×.

Если разместить фразу не удалось, сохранить её аудио и явно отметить конфликт.
Не скрывать его обрезанием речи, выходом дорожки за длительность видео или продлением
видео. Определить поведение просмотра неполного результата и возможность повторить
проблемную реплику после изменения текста/голоса.

### 7. Фоновый звук

Подобрать и проверить локальную модель разделения речи и фона, совместимую с GPU
и подходящей лицензией. Собрать RU-дорожку из выделенного фона и синтетической речи;
оценить артефакты на реальном примере.

При неудаче разделения не выдавать смесь с английской речью за чистый дубляж.
Предусмотреть явно обозначенный режим с приглушённым оригиналом либо только русской
речью. Разделение может использоваться также для подготовки образцов спикеров;
порядок зависимых этапов уточнить при реализации.

### 8. Дорожка и интерфейс

Разместить фрагменты по исходной шкале, сохранить паузы, выровнять громкость,
предотвратить клиппинг. Длительность RU-дорожки должна совпадать с видео в пределах
зафиксированного допуска кодека. Обеспечить синхронную перемотку, выбор оригинала/RU
и скачивание дорожки. Не перекодировать видео без необходимости.

### 9. Проверка и применение

Добавить содержательные тесты сегментации, пауз и перекрытий, соответствия ID,
отсутствия аудита перевода, разделения полного и адаптированного текста, ограниченных
повторов, конфликтов тайминга, длительности дорожки, кэша и совместимости записей.

Запустить `npm run verify --workspace @daevox/transcription-backend` и необходимые
проверки изменённого интерфейса. Выполнить реальный тест на коротком доступном видео.
Проверить начало, середину и конец, перемотку, голоса и сохранение фона. Подготовить
воспроизводимый отчёт с версиями, фактическим оборудованием, результатами и ограничениями.
Перед перезапуском backend убедиться, что активной обработки нет.

## Критерии приёмки

- [x] Работает весь конвейер от источника до переключаемой и скачиваемой RU-дорожки.
- [x] Контекст общий для ролика; полные исходные реплики доступны переводчику.
- [x] Перевод принимается по наличию результата, без проверяющей модели и эвристик качества.
- [x] Полный и адаптированный переводы сохранены раздельно.
- [x] Голоса спикеров используют устойчивые образцы, запасной режим явно обозначен.
- [x] Адаптация выполняется до основного TTS; повторные попытки ограничены и локальны.
- [x] Исходное видео не продлевается; переполнения видны и не скрываются обрезанием слов.
- [x] RU-дорожка сохраняет фон либо явно обозначает выбранный запасной режим.
- [x] Повторная обработка реплики использует промежуточные результаты без полного перезапуска.
- [x] Старые записи, отмена, прогресс, удаление и воспроизведение не сломаны.
- [x] Автоматические проверки пройдены; приложены реальный медиапример и отчёт синхронизации.
