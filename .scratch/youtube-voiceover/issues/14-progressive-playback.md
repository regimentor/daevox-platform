# Просмотр до завершения озвучки

Status: resolved
Type: task

## Решение пользователя

Разрешить просмотр с переводом, как только готовы первые примерно 20 секунд,
пока остальная озвучка продолжает готовиться.

## Answer

- Последовательно подтверждённая временная шкала поступает в один FFmpeg-кодировщик.
  Перевод смешивается с тем же режимом фона, что и финальная дорожка.
- Кодировщик публикует неизменяемые HLS-сегменты примерно по 4 секунды и атомарно
  обновляет EVENT-плейлист. Порог открытия плеера — 20 секунд непрерывно доступного
  аудио; для короткого видео достаточно всей дорожки.
- Видео подготавливается параллельно с озвучкой; финальная сборка использует его
  повторно. Промежуточный видеофайл публикуется атомарно.
- hls.js загружает новые сегменты в существующий audio element. Плеер начинает
  с начала, не перескакивает к краю потока, останавливается у границы готового
  звука и автоматически продолжает после расширения доступного участка.
- Завершение финальной сборки не меняет источник уже открытого плеера. Сегменты
  сохраняются для него; новый просмотр и скачивание используют итоговый файл.
- Превью имеет отдельное поколение на каждый запуск. HTTP разрешает только
  опубликованный плейлист и сегменты; временные файлы и журнал недоступны.
- Отмена завершает кодировщик, подготовку видео и фоновые очереди.
