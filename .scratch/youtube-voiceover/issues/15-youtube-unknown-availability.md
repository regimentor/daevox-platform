# Неизвестная доступность YouTube-видео

Status: resolved
Type: task

## Причина

Для `2Xiljy4xzbc` yt-dlp вернул `availability: null`, `is_live: false`,
`live_status: not_live`. Фильтр принимал только явное `public`, поэтому
отклонял источник до скачивания и скрывал причину за `invalid_media`.

## Answer

Неизвестная доступность допускается к скачиванию; явно непубличные источники
и незавершённые трансляции по-прежнему отклоняются. Причина отказа фильтра
сохраняется, даже если yt-dlp возвращает `None` при пропуске источника.
Worker передаёт безопасное сообщение с кодом `unsupported_source`.

Проверено реальное скачивание указанного видео исправленным `acquire`:
103 374 919 байт, длительность 367,50 с, ffprobe видит audio и video.
Временный файл удалён. Добавлены регрессионные проверки неизвестной/публичной
доступности, ограничений, трансляций и передачи сообщения ошибки из worker.
