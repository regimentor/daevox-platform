# Воспроизведение YouTube с подготовленной локальной озвучкой

Type: research

Assignee: codex

## Question

Какие варианты позволяют смотреть готовую запись YouTube с локальной синтезированной дорожкой: встроенный YouTube-плеер или локально сохранённое видео? По первичным источникам исследовать управление временем, паузой, seek и скоростью, ограничения embed/autoplay, выдачу локальных медиа и Range. Указать технические ограничения и условия YouTube по получению/воспроизведению контента со ссылками, без обещания доступности любых роликов. Сопоставить с текущим acquisition только аудио. Не скачивать видео, не реализовывать плеер.

## Answer

Исследованы официальные YouTube API/Terms, HTML Standard, HTTP Range и Chrome autoplay. Embed технически управляем, однако YouTube Developer Policies прямо запрещают альтернативные аудиодорожки через API; считать его разрешённой базой озвучки нельзя. Локальный video artifact позволяет контролировать просмотр при отдельно обеспеченном допустимом получении исходника. Текущий acquisition не сохраняет устойчивый video artifact. Выбор входа, плеера и баланса дорожек остаётся за последующими решениями с пользователем.
