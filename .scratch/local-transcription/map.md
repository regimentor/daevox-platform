# Локальная транскрибация аудио, видео и YouTube

Labels: wayfinder:map
Status: resolved

## Destination

Согласованная спецификация локальной GPU-транскрибации: отдельный FastAPI-бэкенд на Python/uv и вкладка в apps/web-client. Карта завершена, когда выбор стека, продуктовые правила, контракты и критерии приёмки достаточны для реализации.

## Notes

- Пользователь выбрал результатом карты спецификацию; реализация следует после согласования.
- Источники: аудиофайл, видеофайл, публичное видео YouTube. Язык русский или английский. Первоначальный ориентир в три часа пересмотрен пользователем: программные лимиты размера и длительности не вводятся.
- Модель работает локально на GPU. Загрузка модели допускается только после инициации транскрибации из UI, никогда при старте бэкенда.
- Результат автоматически сохраняется локально на бэкенде в TXT и JSON с временными метками; скачивание через UI не требуется.
- UI показывает текущий этап, измеримый прогресс и распознанный текст по мере появления.
- Очередь не входит в текущую версию.
- Дополнение пользователя: обязательно разделение по спикерам. Для UI настроить Vite proxy с точным префиксом `/trancription-api/`. Исследование диаризации и её продуктовые правила вынесены в отдельные дочерние задачи.
- Проверка окружения 2026-09-10: Ryzen 9 9950X, 62 GiB RAM, RTX 5080 и RTX 4070 Ti. Kernel driver NVIDIA 610.57.04 видит обе карты, но в окружении агента нет /dev/nvidia*; nvidia-smi не работает. Доступность CUDA, VRAM и inference не подтверждены. Установлены uv 0.12.12, Python 3.14.7, FFmpeg n9.0.1. Это наблюдения, а не выбранный стек.
- Применять wayfinder; обсуждения — grilling и domain-modeling; исследования — research. Не смешивать операцию транскрибации с AgenticTask из существующих глоссариев без отдельного решения.
- Трекер: docs/agents/issue-tracker.md. Открытая невзятая задача без Status; взятая — claimed с Assignee; завершённая — resolved. Blocked by содержит номера. Решение хранится только в Answer дочерней задачи.

## Decisions so far

- [GigaAM-v3 для русской речи](issues/11-gigaam-russian.md): e2e_rnnt для русского и авто-RU, Whisper для английского; проверены реальные короткие и полный 97-минутный запуск.

- [Цельные реплики спикеров](issues/10-speaker-blocks.md): границы ASR и наложения не дробят речь одного назначенного спикера; HTTP/SSE, UI и экспорт проверены.

<!-- Только указатели на разрешённые дочерние задачи. -->

- [Жизненный цикл транскрибации и локальных файлов](issues/03-operation-lifecycle.md): согласованы один запуск с отменой, возвращение к текущему прогрессу, хранение файлов и границы источников без программных лимитов.

- [Совместимость GPU-стека и обработка длинных источников](issues/01-stack-research.md): собраны матрица GPU/Python/CUDA, ограничения длинных источников и кандидаты интеграции; окончательный выбор требует решений и проверки реального GPU.

- [Выбор модели, GPU и жизненного цикла модели](issues/02-runtime-choice.md): выбраны полная large-v3 с приоритетом качества, GPU-конфигурация, ленивая загрузка и освобождение памяти, язык и Python/uv.

- [Локальное разделение записи по спикерам](issues/06-diarization-research.md): исследованы локальные кандидаты, доступ к весам, GPU-совместимость и ограничения финальных/ранних меток; продуктовый выбор не сделан.

- [Метки спикеров в UI и результатах](issues/07-speaker-behavior.md): выбраны Community-1, доступ к весам, параллельная работа на двух GPU и анонимные метки в живом тексте и файлах.

- [Контракт FastAPI и вкладки транскрибации](issues/04-ui-contract.md): согласованы API/UI, proxy, события двух GPU, отмена, ошибки диаризации и совмещение текста со спикерами.

- [Спецификация и критерии приёмки локальной транскрибации](issues/05-acceptance-spec.md): согласованы итоговая спецификация и порядок автоматических, GPU- и качественных проверок; план готов к реализации.

## Out of scope

- Реализация и запуск сервиса в рамках карты планирования.
- Очередь и пакетная обработка файлов.
- Скачивание результата из UI.
- Непубличные YouTube-видео.
- Текущие прямые трансляции YouTube; поддерживаются готовые публичные записи.
- Проработка восстановления после сбоя или перезапуска бэкенда — отложена пользователем.
- История прошлых запусков в UI — отложена пользователем.
- Перевод — исключён пользователем из текущей задачи.
