# Интегрировать middleware в HTTP transport

Добавить application-, controller- и handler-level middleware в выполнение HTTP-запроса согласно
[`../spec.md`](../spec.md).

## Требования

- Работать через TDD и писать исходный код и тесты только в `.js`.
- Добавить строгую опцию `http.middleware` с проверкой и снимком массива при создании `Application`.
- Добавить необязательное `static middleware` в `HttpControllerBase`-контракт и проверять его
  атомарно при регистрации контроллера.
- Расширить декларацию HTTP-маршрута необязательным `middleware`, сохранив отклонение неизвестных
  полей, атомарную регистрацию и независимость от последующих мутаций метаданных.
- Создавать новый `ctx.state` с null prototype для каждого успешно найденного HTTP-запроса.
- Добавить замороженный `ctx.route` с `{ method, path, handler }` без класса контроллера.
- Выполнять цепочку в порядке application → controller → route → HTTP handler.
- Выполнять окончательную нормализацию `HttpResponse` один раз после завершения всей цепочки.
- Обрабатывать `HttpError` как ожидаемый HTTP-ответ, а произвольную ошибку middleware передавать в
  `http.onError` и преобразовывать в `500`, не затрагивая другие запросы или процесс приложения.
- Сохранить существующее поведение инфраструктурных ошибок до маршрутизации.
- Добавить двуязычный JSDoc с `@public`/`@private` для всего изменённого production-кода.

## Критерии приёмки

- Integration-тесты доказывают порядок всех трёх уровней и обратное разворачивание цепочки.
- Application-level middleware не вызываются для `404`, `405`, ошибки JSON и превышения body
  limit согласно спецификации.
- `state` изолирован между параллельными HTTP-запросами.
- Short-circuit не создаёт экземпляр контроллера и не вызывает последующие middleware.
- Произвольный `throw new Error()` даёт только текущему запросу `500`; следующий и параллельный
  запросы успешно обслуживаются.
- Мутация пользовательских массивов после создания приложения или регистрации контроллера не
  меняет цепочки.
- `npm run docs:build` и HTTP unit/integration-тесты завершаются успешно.
